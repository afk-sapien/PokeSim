MAKE YOURSELF AT HOME

Settings and backups

Simulation settings

Set the pace for all adventures and choose how many can run at once.

This pace applies to every adventure. A slower pace means slower adventures and fewer notifications over time. Use 1× for everyday play. Max runs as fast as possible and is intended for testing.

Backups

Create a consistent snapshot of this application and its adventures. Running adventures may briefly stop while their saves are collected.

Import an adventure

Close PokeSim

Closing this browser tab keeps adventures running. Save and quit stops all adventures and closes the application.

New adventure

Your ROM stays in this application. Reusing it creates an independent adventure.

The Mew gift and League victory rewards are enabled for new adventures. You can change these in adventure Settings.

Adventure settings

Receive a level-5 Mew in the PC after defeating the Champion rival. Enabling this later also grants a missed Mew once, when there is room in storage. Adventures that have already owned Mew do not receive another event gift.

League rewards apply only to victories earned while enabled. Past victories do not receive catch-up rewards. Each win awards one random level-5 Pokémon from the unlocked pool. Fossils unlock after acquiring any fossil Pokémon, Eevee after acquiring its family, and both dojo fighters after beating the Karate Master. Mr. Mime and Jynx unlock individually after first acquisition. Stop this adventure to change these optional rewards.
