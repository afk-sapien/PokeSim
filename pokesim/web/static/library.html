    Game cartridges

    One slot for each game. Drop a ROM file on any slot, or choose Upload. PokeSim recognises the game from the file itself and puts it in the right slot.

    Clean English ROMs only, as .gb, .gbc or a ZIP holding one. Your ROMs stay in this application, and every adventure keeps its own save.

    Pokémon artwork

    Loading artwork settings…

    Portraits come from your own ROM. Optionally install the community pack, one download that covers every supported game: Red, Blue, Yellow, Gold, Silver and Crystal. Each adventure then shows the artwork of its own version.
