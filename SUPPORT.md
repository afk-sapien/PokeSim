# Getting help

- **Questions, setup help, and ideas:** start a thread in
  [Discussions](https://github.com/afk-sapien/PokeSim/discussions).
- **Bugs:** open a [bug report](https://github.com/afk-sapien/PokeSim/issues/new/choose)
  with your release, operating system, ROM SHA-1 (never the ROM itself), and sanitized logs.
- **Security issues:** report them privately as described in [SECURITY.md](SECURITY.md).

Start with the [README](README.md), the [documentation index](docs/README.md), and
[self-hosting](docs/self-hosting.md). PokeSim is an experimental personal project
maintained in spare time, so replies are best effort.
