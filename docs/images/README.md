# README screenshots

Actual browser captures from the owner’s running adventures, approved for use in
the public README. No game state or statistics were fabricated for these images.

## Current README images

| File | Captured | View |
| --- | --- | --- |
| `gen2-live.gif` | October 16, 2026 | Crystal battling Will of the Elite Four, with 16 badges and 251 registered |
| `gen1-live.gif` | October 16, 2026 | Blue walking Victory Road into a wild Geodude battle, with 151 registered |
| `journal-panel.jpg` | October 16, 2026 | Yellow journal with a League victory, a rival win and a starter reward |
| `stats-panel.jpg` | October 16, 2026 | Crystal overview totals and milestones |
| `pokedex-panel.jpg` | October 16, 2026 | Crystal Pokédex with 251 of 251 registered |
| `pc-panel.jpg` | October 16, 2026 | Crystal PC boxes with the current box of new catches |
| `library.jpg` | October 16, 2026 | Library with Red, Blue, Silver, Crystal, Gold and Yellow all running |

All captures come from the owner's home server running public version 0.5.0, in
the dark theme. Simulation states and speed were not changed for the captures.

Both GIFs are eight-second headless browser recordings of the Live page at a
900-pixel viewport, from the top of the page through the controls. They loop at
six frames per second and measure 720 × 940 pixels. The colored party portraits
and Pokédex art come from the owner's optional community sprite pack. The game
screen itself is rendered by the emulator.

The panels use a 1265-pixel viewport. Journal and Stats panels are 712 pixels
tall. Pokédex and PC panels are 1000 pixels tall. The Library capture ends after
the second row of adventures. Three Generation II cards show the Library's
"Stuck?" note, which was present on the live server at capture time.

The README arranges each pair in a two-column Markdown table. Matching dimensions
keep the panels aligned. Each image links to the original for a full-size view.
Earlier captures are available in the
[0.4.19 image archive](https://github.com/afk-sapien/PokeSim/tree/v0.4.19/docs/images).

Keep screenshots free of browser chrome, local file paths, credentials and
private settings. Choose views through the actual interface without altering
game data. Keep images in the source package so the README also works in
source downloads. Record which portrait source is active when making a capture.
