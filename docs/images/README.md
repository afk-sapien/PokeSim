# README screenshots

Actual browser captures from the owner’s running adventures, approved for use in
the public README. No game state or statistics were fabricated for these images.

All captures come from the owner's home server running public version 0.5.1, in
the dark theme. Simulation states and speed were not changed for the captures.

Every capture uses a 1440-pixel desktop viewport. Both GIFs are eight-second
headless browser recordings of the Live page, from the top of the page through
the controls. They loop at six frames per second and measure 1080 × 829 pixels.
The colored party portraits and Pokédex art come from the owner's optional
community sprite pack. The game screen itself is rendered by the emulator.

Journal and Stats panels are 1440 × 810 pixels. Pokédex and PC panels are
1440 × 1138 pixels. The Library capture ends after the second row of adventures.

The README arranges each pair in a two-column Markdown table. Matching dimensions
keep the panels aligned. Each image links to the original for a full-size view.
Earlier captures are available in the
[0.4.19 image archive](https://github.com/afk-sapien/PokeSim/tree/v0.4.19/docs/images).

Keep screenshots free of browser chrome, local file paths, credentials and
private settings. Choose views through the actual interface without altering
game data. Keep images in the source package so the README also works in
source downloads. Record which portrait source is active when making a capture.
